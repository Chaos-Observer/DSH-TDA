```
┌─────────────────────────────────────────────────────┐
│ L5 目标与元认知    目标状态机 / 漂移校准 / 长程规划    │
├─────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────┤
│ L2 记忆层          旋转上下文 / 单事实时间线          │

└─────────────────────────────────────────────────────┘
横切：认知资产卫生层（统一生命周期 / 治理 / 更新维护）
```

### 2.1 运行时判定

| 层 | 是否自建 | 说明 |
|---|---|---|
| 插件基座（Cordis / 事件总线 / 状态管理 / SessionLog） | ❌ 复用 DSH | 不重造 |
| **Agent 主循环 Harness** | ✅ 自建 | DSH 插件形态。目标状态机驱动、预算/终止界、上下文组装、子代理派发、契约强制、审批节点、审计序列化 |
| **工作流执行器** | ✅ 自建或接现成 | XState / Temporal / 轻量 DSL（决策点 4） |
| **常驻进程 / 定时 / 事件触发** | ✅ 轻量自建 | 心跳、周期性任务、事件监听；否则自主排任务无法跨会话活 |

## 3. 认知资产卫生层

统一主生命周期（与需求文档 §3.6 一致）：`草稿 → 验证中 → 已固化/已发布 → 已退役`

统一元数据：来源凭证（用户原始/执行验证/模型自产）、置信度、复用次数、验证次数、跨任务关联度、时间戳、轨迹链接、版本、上游冲突标记。

- **脏资产处理**：按需求文档 §3.6 表格执行（回放验证晋升 / 凭证分阶固化 / 冲突检测 / 容量上限淘汰）
- **更新维护闭环**：升格 / 降级退役 / 协调同步，由 coach 元进程周期后台驱动；维护设吞吐上限
- **外部验证阀**：固化与晋升的唯一通路，不靠 LLM 即时判断

## 4. 各层技术选型

| 模块 | 落地选型 |
|---|---|
| 基座/运行时 | DSH Cordis 复用 + 自建 Harness 插件 + 工作流执行器 + 轻量常驻进程 |
| 任务持久化 | SQLite（任务树图 + 目标状态机 + 执行预算 + 人类注意力配额） |
| 事实时间线 | SQLite + 向量库（SQLite-vec / Qdrant / Chroma） |
| 旋转上下文 | 分页 memo 常驻 + 完整 page 按需 + **perplexity gate**；gate 依赖模型 logprobs，黑盒 API 不可得时**降级**为"预算内优先级排序 + 静态截断"，机制不失效；替代不确定性源 = 轨迹预测器 mismatch；**约束钉扎区豁免压缩**；转换必须**段可分解/KV-cache 友好**；预算按百分比配比 |
| 记忆召回（分阶段） | P1 最小版：任务状态相关 + 时间衰减 + 被动语义 + **provenance gate**；P2+ 完整版：动量/情感权重引力场 + 主动策略召回 |
| 轨迹资产 | 复用 DSH Trajectory 三态消费：回放（审计/rehearsal）/ 预测（相似 transition 检索 → 状态/风险预测 + mismatch 信号喂 coach）/ 辅助召回（情景记忆） |
| 治理管道 | 统一卫生层（验证阀 / 退役 / 凭证分层 / 更新维护闭环） |
| 编排 | 工作流外部化定义 + 执行器（决策点 4） |
| 子代理 | Lead（前沿模型·规划审查）+ Sidekick（廉价模型·执行），各持独立上下文；高风险任务加 critic 互审 |
| 自成长 | coach（元进程·复盘重放）+ athlete（执行进程）双环；coach 优化跨模型可迁移 |
| 人机监督落点 | Harness 内含：注意力配额计入预算、编排显式审批节点、AgentState 序列化写时间线供回放 |
| 安全 | 需求文档 §5 五硬条款：约束钉扎 / 写入检疫 / provenance 链+gate / 控制流-数据流分离 / Trajectory 审计基线 |

## 5. 实施路线蓝图（含可验证里程碑）

### P0 · 最小可用闭环
目标状态机 + 任务树持久化(SQLite) + 单事实时间线 + 旋转上下文(分页 + pinned 约束区 + gate 降级版) + 子代理隔离(Lead+Sidekick 初版) + 工作区语义理解初版 + 轨迹资产接入(Trajectory 审计/replay)。
**里程碑**：一个真实任务机读状态跟踪到完成；重启/切会话后状态与约束不丢；主上下文只留决策；pinned 约束不被压缩。

### P1 · 记忆与能力
引力场最小召回(含 provenance gate) + 记忆治理管道(检疫/验证/退役) + 元思维库初版 + 目标漂移检测 + 轨迹预测器 v1。
**里程碑**：重复任务第二次提速且不出错；漂移信号被捕获并温和校准；记忆投毒来源被拦截；mismatch 信号可用。

### P2 · 自成长与编排
coach 元进程 + 资产更新维护闭环 + 技能生命周期(回放/晋升/退役) + 引力场完整版 + 工作流外部化 + 执行器 + 插件调研 Agent。
**里程碑**：新技能经回放晋升且不失控（退役承重）；流程模板可复用迭代；插件社区被自动评估。

### P3 · 长程与信任
分层知识图谱(Wiki 蒸馏) + 人类监督/审批/审计 + 跨模型身份持久化 + 安全加固。
**里程碑**：长程运行无目标漂移/技能失控；每步决策可审计可回放；跨模型迁移不丢身份。

## 7. 对标与演化依据（摘要）

- Devin Fusion：Lead+Sidekick 双模型协同，省 20–46% 成本
- Meta HYPERAGENTS：coach/athlete 元进程自进化，SWE 20%→50%，跨模型迁移
- WorldEvolver：轨迹预测 + **预测-观测 mismatch → 启发式规则提炼**（coach 内核）；Selective Foresight（低置信预测过滤）
- Voyager：技能库两铁律（前置依赖检查 + 验证才入库）——外部验证阀的原始范式
- Graphiti/Mem0/Letta：双时序 + invalidation、add-only 覆盖、自编辑核心记忆——事实时间线与工作记忆的参照实现
- MUSE-Autoskill / Ratchet：技能生命周期治理、退役承重（LLM 自生成技能提升 +0.0 的教训）
- Chroma Context Rot / SmoothAgent：上下文衰减实证（18/18 模型）与段可分解转换、KV-cache 友好
- Governance Decay / Sleeper / MemoryGraft / MINJA：压缩吃约束、记忆投毒 → C6 + §5 五硬条款的依据
- 安全反面：孤立自进化 Agent 社会对齐漂移（青蛙温水）→ C1 漂移校准 + 外部验证阀的必要性
