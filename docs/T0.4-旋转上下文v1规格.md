## 1. 设计裁定

| # | 裁定 | 理由 |
|---|---|---|
| J1 | **复用 DSH compaction 为执行基座，自建层只做三件事**：① pinned 豁免区（C6）② 统一上下文分页树（memo/page）③ 困惑度 gate + 降级策略。不改 compaction 内核，经其 patch 点（`dsh-compaction-basic` retained-tail 策略）与事务括号挂载 | T0.0 已核实：surface 遮蔽式（append-only 永不删、shadowedSeqs 权威集）、pressure/context-overflow 双档、tokenMeter 独占计量、tool-call/result 配对边界保持全部现成；重写压缩管道=扔掉崩溃可检测与审计性 |
| J2 | **pinned 区不经 session surface**：由 context 插件每轮从 domain 数据源（T0.1 `constraint_snapshots` + 焦点目标节点 + T0.2 焦点任务硬约束）重新渲染，注入在 system 段之后、surface 投影之前；因此结构上豁免一切压缩/折叠/降权 | C6 硬条款 + 实证（压缩致违规 0%→30%，~47 token 钉扎恢复 0%）。走 surface 就要进 shadowedSeqs 管辖，豁免不彻底；每轮重渲染保证 pinned 内容与权威 domain 同步（不会展示过期约束） |
| J3 | **统一上下文分页树**：轻量 memo 常驻（焦点目标/当前任务/最近决策）+ 完整 page 按需加载（page 记录 T0.3 时间线 seq 范围）；**会话切换=任务切换=换 page**，底层时间线不变；默认折叠策略="只显示当天+焦点相关页"展开，其余折叠为 memo 级摘要 | §3.4.2 分页树三条款逐条落地；"权威状态不得只靠当天上下文"由 pinned+memo 双通道保证（C1） |
| J4 | **KV-cache 友好为硬约束**：① 组装输出按"稳定前缀→易变后缀"严格排序（system/pinned → memo → history → injection）；② 换页/遮蔽只做整段操作，禁止段中截断与已缓存前缀的内容改写；③ 预算按**百分比配比**（四区）而非绝对 token | §3.4.2 明文：段可分解（前缀转换独立于未来 token），否则吃掉 DSH 缓存命中红利、TTFT 爆炸；预算按百分比配比 |
| J5 | **困惑度 gate v1 = 段级近似**：周期性（压力触发或每 K 轮）采样 logprobs → 计算各 history 段的"被推断度"（该段信息在当前生成前缀中的可推断性 proxy）→ 高被推断度段优先入遮蔽候选。逐 token 实时计分（§3.4.2 理想形态）留 v2 | 理想形态逐 token 计分在每次生成时对每段做反事实推断，成本不可施工；段级近似保持同一机制内核（可推断度→压上下文→预算留给不确定点），v1 可验证、v2 可深化（U4） |
| J6 | **双路径必须并存**：`gate.mode='perplexity'\|'static'`。logprobs 不可得（黑盒 API / adapter 透出层未就绪 / 采样失败）→ 自动降级 static = 预算内优先级排序+静态截断，**机制不失效**；P0 默认 static，adapter 透出实测通过后切 perplexity | §3.4.2"降级策略（必须）"明文；替代不确定性源=轨迹预测器 mismatch 信号（T1.3，P1 接入，本规格留 seam） |
| J7 | **logprobs 透出层契约**（adapter 改造）：请求 `logprobs:true` + `top_logprobs≤20`（DeepSeek 上限）；聚合时过滤 `-9999.0` 哨兵；`top_p` 思考模式下限 0.95 的约束在 gate 采样请求上单独遵守 | T0.0 spike 结论三条落地注意；DSH llm-streaming 词汇裁剪是唯一缺口，属可办透出层 |
| J8 | **组装即审计**：每轮 `assemble()` 产出的段清单 + 遮蔽记录（seq 集+原因+模式）双写——log-only session event `context/assemble` + 汇入 T0.3 时间线（source=conversation） | §4"AgentState 序列化写入事实时间线，可回放"；T0.7 回放要能还原"当时模型看到了什么"；model-visible⟺logged 不变量 |

## 2. 状态模型

context 插件自身无 phase 状态机；其"状态"= **每轮的组装结果**（派生）：

```
AssembledContext = [
  system            （稳定，缓存友好）
  pinned*           （J2：C6 四类，豁免区，每轮重渲染）
  memo              （常驻轻量：焦点目标/当前任务/最近决策）
  history[segments] （surface 投影 − shadowedSeqs − 已折叠页）
  injection*        （T1.1 召回注入，降权首选）
]
```

- **遮蔽决策**（谁进 shadowedSeqs）两个来源：DSH compaction 双档触发（pressure/context-overflow）+ 自建 gate（perplexity/static）。后者经 compaction 的同一权威集落地，不另立遮蔽机制（J1）；
- **分页树**：`PageTable` 记录 pageId → {label(goal/task), timelineRange, tokenEstimate, resident, lastAccess}；`pageIn/pageOut` 只在段边界整体换页；
- **预算四区**（J4 百分比，默认值待标定 U3）：pinned 8–12% / memo 8–12% / history 50–65% / injection 15–25%；剥夺顺序 = injection → history → memo，**pinned 不参与剥夺**。

## 3. 数据模型

### 3.1 `PinEntry`（C6 钉扎项）

```ts type-equiv
/** pinned 区条目。内容每轮从 domain 数据源重渲染，不存正文快照。 */
interface PinEntry {
  readonly id: PinId                       // branded，pin-<n>
  readonly kind: 'goal' | 'criteria' | 'constraint' | 'safety'   // C6 明文四类
  readonly sourceKind: 'goalTree.focus' | 'constraint_snapshots' | 'taskPool.focus'
  readonly sourceRef: string               // goalId / GoalId / taskId
  readonly render: (ctx: RenderCtx) => string   // 裁剪渲染器（产出 ≤ N token 的稳定文本）
  readonly maxTokens: number               // 单项帽（超帽=渲染器 bug，加载即拒）
  readonly createdAt: number
}
```

### 3.2 `AssembleRecord`（审计记录，append-only）

```ts type-equiv
/** 每轮组装事实。双写 session event + T0.3 时间线。 */
interface AssembleRecord {
  readonly sessionId: SessionId
  readonly round: number
  readonly segments: { kind: SegmentKind; ref?: string; tokenEstimate: number }[]
  readonly shadowed: { seqs: number[]; reason: 'pressure' | 'context-overflow' | 'gate-perplexity' | 'gate-static' | 'page-fold' }
  readonly budget: { pinnedPct: number; memoPct: number; historyPct: number; injectionPct: number }
  readonly gate?: { mode: 'perplexity' | 'static'; sampledTokens?: number; droppedSegmentIds: string[]; fallbackReason?: string }
  readonly at: number
}
```

### 3.3 存储落点

| 数据 | 落点 | 说明 |
|---|---|---|
| pinned 定义（PinEntry） | context 插件 domain（sqlite，layout single） | 数量小（十条级）；内容不存、只存渲染规则引用 |
| PageTable | 进程内 + 启动时从 T0.3 时间线/taskPool 重建 | page 是视图不是权威；权威在时间线（T0.3） |
| AssembleRecord | log-only session event + T0.3 timeline chunk（source=conversation） | J8 双写；回放源 |
| gate 配置 | 插件 Config（mode、采样周期 K、静态优先级表） | cordis.yml 可覆盖 |

## 4. 不变量与服务 API

### 4.1 不变量（编译期/加载即校验）

1. **C6 豁免绝对化**：pinned 段任何条件下不进 shadowedSeqs、不因预算不足被截断——超预算时只剥夺 injection/history/memo；
2. **前缀稳定**：同 focus 状态下，相邻两轮组装输出的 system/pinned/memo 前缀段逐字节相同（KV-cache 命中的可判定条件）；
3. **段边界完整**：history 段的进入/离开只发生在 tool-call/result 配对边界或 page 边界（继承 compaction 的配对边界保持）；
4. **遮蔽必经权威集**：自建 gate 的遮蔽必须转化为 compaction shadowedSeqs 条目，禁止旁路删除 surface 内容；
5. **双路径可达**：`gate.mode='static'` 下不调用任何 logprobs 依赖亦可完成全部压缩动作（机制不失效）；
6. **pinned 同步**：pinned 渲染数据源（goalTree/taskPool/constraint_snapshots）变更后，下一轮 assemble 必然反映（无过期窗口）；
7. **组装留痕**：每轮 assemble 必产 AssembleRecord 且可从 session log 重建（model-visible⟺logged 自检）。

### 4.2 `ctx.context` 服务方法

```ts type-equiv
interface ContextService {
  assemble(session: Session, round: number): AssembledContext   // 每轮注入前调用（J4 排序+J2 pinned+J3 分页）
  pin(entry: PinEntry): PinEntry
  unpin(id: PinId): void
  pageIn(pageId: PageId): void                                   // 段边界整页换入
  pageOut(pageId: PageId): void                                  // 折叠为 memo 级摘要后换出
  gateSample(sample: LogprobsSample): GateDecision               // perplexity 路径输入（J5/J7）
  registerScorer(scorer: SegmentScorer): void                    // T1.1 引力场计分器 seam（v2 启用）
}

interface LogprobsSample { tokens: { token: string; logprob: number; top: { token: string; logprob: number }[] }[] }  // 已过滤 -9999.0 哨兵
```

- `assemble` 内部序：取 focus（goalTree/taskPool）→ 渲染 pinned → 取 memo → 按 PageTable 展开 history → 挂 injection（T1.1）→ 预算检查（超区按剥夺序处理）→ 遮蔽决策（compaction 双档优先，gate 补充）→ 产 AssembleRecord；
- `gateSample` 无样本时返回 `{mode:'static', fallbackReason}`（J6 自动降级）；
- scorer seam：`SegmentScorer = (segment, ctx) => number`（0–1 放大/降权分），v1 内置静态优先级表，T1.1 注册引力场计分器后启用动态分。

## 5. 与 DSH 的对接点

| 对接面 | 机制 |
|---|---|
| compaction 基座 | `ctx.compaction` 事务括号 + shadowedSeqs 权威集 + `ctx.tokenMeter` 计量；retained-tail 策略经 `dsh-compaction-basic` patch 点替换为"pinned 豁免 + 分页折叠"策略 |
| logprobs 透出 | DSH llm adapter 透出层（J7 契约）：请求参数透传 + 响应聚合 + 哨兵过滤；流式组合行为留实测（U2） |
| 模型可见性 | pinned/memo 段经 `agent.inject()` 或 system-prompt section（`context:pinned`，order 紧随 `task:state`）注入；assemble 结果双写（J8） |
| T0.1/T0.2 | `constraint_snapshots`/焦点目标/焦点任务 = pinned 数据源；焦点切换触发 pageIn/pageOut |
| T0.3 | page 的 seq 范围索引时间线；AssembleRecord 汇入时间线（conversation source） |
| T1.1 | injection 区内容 = 引力场召回输出；`registerScorer` 是其挂载点 |
| T1.3 | mismatch 信号作为 static 路径的"替代不确定性源"输入（P1，seam 预留） |
| T0.7 | `context/assemble` 事件落盘 → fork/resume/replay 还原每轮可见上下文 |

## 6. 验收标准（对 Gate G0 的贡献项）

1. **G0-④**：模拟 pressure 与 context-overflow 双档触发后，pinned 四类条目（目标/完成标准/硬约束/安全策略）逐字节完整在场（C6 硬条款自检）；
2. **G0-③**：任务切换 = pageOut 旧任务页 + pageIn 新任务页；换页后上下文含新任务页、底层时间线 seq 连续不变（T0.3）；
3. **KV-cache 友好自检**：同 focus 连续两轮组装输出的前缀段逐字节相同；预算四区按百分比配比生效（超区时 injection 先剥、pinned 不动）；
4. **双路径**：static 路径在无 logprobs 环境下独立完成压缩全流程；perplexity 路径（有 key 后）正确透出 top_logprobs≤20、过滤 -9999.0、采样失败自动降级；
5. **可审计**：任取一历史轮次，可从 session log 重建其 AssembleRecord（段清单+遮蔽原因+预算配比），与 T0.7 回放交叉验证一致；
6. pinned 数据源变更（如约束快照更新）在下一轮 assemble 生效（无过期窗口）。
